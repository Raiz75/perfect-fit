# Glossary

| Term | Definition |
|---|---|
| PERFIT | Church ministry fit assessment platform. Helps volunteers discover which ministries best match their skills, interests, and personality. |
| church_code | A unique 9-character alphanumeric code generated per admin user during registration. Links assessment submissions to a specific church. |
| eligible_ministry | Comma-separated list of ministry IDs (or names) that the assessee qualifies for based on their demographics, skills, and responses. Computed during the assessment scoring phase. |
| ai_interpretation | Natural-language summary of assessment results generated by DeepSeek AI, stored in the user_report. |
| Ministry Category | High-level grouping of ministries (6 total, e.g. Worship, Outreach, etc.). Used for interest & passion assessment phase. |
| Ministry | A specific church ministry role (29 total). The target entity being assessed for fit. |
| Skill | One of 8 skill areas (Music, Technology, Writing, Technical, Speaking, Accounting, Mentoring, Bible Knowledge) rated during assessment Phase 2. |
| Phase 1 | Demographics collection (name, email, contact, gender, age, marital status, baptized, time in faith). |
| Phase 2 | Skills self-assessment (8 skills × 5 questions each, 1-6 scale). |
| Phase 3 | Interests & Passions (6 ministry categories × 5 questions each). |
| Phase 4 | Behavioral questions (5 per eligible ministry, filtered by prior phases). |
| CopyDefaults | Action class that duplicates all restriction and question records from admin user ID=1 to a newly registered admin. Enables the multi-tenant church setup pattern. |
